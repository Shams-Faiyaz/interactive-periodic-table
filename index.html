About Valence

Built for students, owned by the community.

No company, no investors — just a free tool that's meant to stay that way.

Created by Legit · Owned by the community

Legit is a developer who wanted to help students actually enjoy learning chemistry — so this free, interactive 3D periodic table got built. All 118 elements, their structures and trends, in one place.

No sign-ups. No email. No phone number. Just open it and explore — guest mode always works, and there's nothing to create an account for.

Open source & free — forever

Want to make it better? You're welcome to use the code, on one condition: keep it open-source and free for everyone, exactly like this. Built for students, owned by no one but the community.

Install it like a real app.

No app store and no download file — it installs straight to your home screen or desktop and even works offline after the first visit.

A

Android (Chrome)

Tap the ⬇ Install app button (top-right), or open the ⋮ menu and choose Install app.

i

iPhone / iPad (Safari)

Tap the Share icon, scroll down, then tap Add to Home Screen.

D

Desktop (Chrome / Edge)

Click the install icon in the address bar, or the ⬇ Install app button. It opens in its own window.

Quick controls

1234 Switch between Table, Sphere, Helix and Grid views.
R Reset — recenters and re-zooms the current view.
/ Search — jump to any name, symbol or atomic number.
click Tap any element for its Bohr model, orbitals, trends and facts.
